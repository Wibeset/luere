Every size, every platform.

One source image in, a complete icon set out — nothing to configure, nothing left to resize by hand.

Web favicons

favicon.ico (16/32/48), PNG set, apple-touch-icon and android-chrome 192/512.

macOS .icns

A single icon.icns compiled from 16 all the way up to 1024, ready for your app bundle.

iOS AppIcon set

A complete AppIcon.appiconset with a 1024px master and Contents.json — drop straight into Xcode.

Multi-resolution favicon.ico (16/32/48/256) plus standalone PNGs from 16 to 256.

A site.webmanifest and a ready-to-paste head-snippet.html so wiring it up is copy-paste.
